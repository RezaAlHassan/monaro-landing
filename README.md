# Monaro landing page

The public landing page and waitlist live at https://getmonaro.app.
The staff application is separate at https://app.getmonaro.app.

## Cloudflare

This repository deploys to the `monaro-landing` Worker using `cf`.
`cloudflare.config.ts` defines the Worker and custom domain. The CLI-generated
`wrangler.config.ts` controls bundling and copies only public assets.
Production waitlist records use the separate `monaro-waitlist` D1 database,
bound as `WAITLIST`. No main-app database or messaging credentials are needed.

Use a Node version supported by the installed `cf` package (22.23+, 24.22+, or 26.12+).

```sh
npm ci
npm test
npm run build
npm run deploy
```

Sign in with `npx cf auth login` before deploying, or set
`CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` through your deployment
service's secret settings. Never commit tokens.

The waitlist schema is `migrations/001_waitlist.sql`. For a fresh deployment,
create its own D1 database and update the ID in `cloudflare.config.ts`, then run:

```sh
npx cf d1 migrations apply e965b291-1214-4a72-8e77-919336eabcb3
```

## Local development

```sh
npm run dev
```

The default local address is http://localhost:5180. Local D1 is separate from
production. Apply the migration locally before testing signup storage:

```sh
npx cf d1 migrations apply e965b291-1214-4a72-8e77-919336eabcb3 --local
```

The original Python/SQLite server remains as a development reference. Cloudflare
runs `worker.mjs`, not Python. Only `public/` contents generated by
`prepare-assets.mjs` are uploaded as static files. Source, databases, and tests
are not served publicly.

## Waitlist and policies

POST `/api/waitlist` accepts JSON `{ "email": "you@example.com", "website": "" }`.
It normalizes email, ignores duplicates, validates request size and origin, and
uses a honeypot. There is no public endpoint listing signups. Submissions save
to D1; signup confirmations and launch emails are not sent automatically.

View signups in Cloudflare > Storage & databases > D1 > monaro-waitlist > Console:

```sql
SELECT email, joined_at FROM waitlist ORDER BY joined_at DESC;
```

Privacy, terms, and deletion pages are independent public routes in
`legal-pages.mjs`. Review these when the operator, contact details, providers,
or product behavior changes. Policy updates in this repository and the app
repository must be kept in sync.

## GitHub automatic deployments

For Cloudflare Workers Builds, connect this repository to `monaro-landing`,
select branch `main`, root `/`, build command `npm run build`, and deploy command
`npm run deploy`. The repository integration and deployment credential must be
authorized in Cloudflare. Git pushes alone do not enable automatic deployment.
